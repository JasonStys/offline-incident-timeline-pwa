# 1.1.0 — durable native incident analysis

Adds a complete unsigned Windows x64 application using the original parser, IndexedDB snapshots, indexes, UTC filters, chart/list and exports. It bundles Electron 44.11.1 and uses a stable private app origin; users need no server, terminal or external runtime. Prepared service-outage and cross-midnight datasets are selectable inside the actual app.

Native operations are acknowledged before mutation and retained through repeated Exit/Close. Explicit exports refuse existing destinations and preserve cancellations. Existing profiles are admitted with bounded ordinary-file/alias checks; unknown data and interrupted-owner evidence are preserved. This remains a trusted single-OS-owner plaintext application, not a multiuser account service or evidence vault.

Corrects ambiguous local-time chart/list labels beside UTC filters and releases the Worker client's state after actual file-read or synchronous transport failures. Browser PWA caching moves to shell namespace v3; IndexedDB version 2 and worker protocol version 1 are unchanged. Browser and native profiles remain separate; import/export explicitly.

The Windows package deliberately uses ordinary app files because ASAR's synthetic file identities cannot satisfy the same-descriptor reader contract. Source/payload hashes are provenance checks, not signatures. Existing published assets/tags and historical Office editions are untouched. Hosted acceptance, release publication and installation are separate steps; see [dated observations](../reports/NATIVE_APPLICATION_2026-11-11.md) and the [native guide](../NATIVE_APPLICATION.md).
